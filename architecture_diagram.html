Migration Engine – Three-Phase Pipeline

📤
1 · Export
  • REST API calls to source
  • Notebooks (DBC format)
  • Workspace files (binary)
  • Jobs, clusters, pools
  • Warehouses, dashboards
  • Users / groups (SCIM)
  • Secret scope names
  • ACL permissions
  • DBFS library files
  • Git repo metadata
  • Unity Catalog SQL
  • Model endpoints
🔄
2 · Transform
  • SP reconciliation scan
  • Create SPs on GCP target
  • Patch SP IDs in all files
  • Azure VM → GCP type map
  • Inject gcp_attributes
  • Map availability policy
  • Strip Azure-only fields
  • Warehouse ID mapping
  • Patch genie_spaces.json
  • Remove AWS references
  • Apply node zone hints
  • Pause job schedules
📥
3 · Import
  • Users / groups (SCIM)
  • Notebooks (migrate tool)
  • Workspace files upload
  • Instance pools first
  • Cluster policies
  • All-purpose clusters
  • Jobs (with pool map)
  • SQL warehouses
  • DLT pipelines
  • AI/BI dashboards
  • Secret scope shells
  • Git repos
  • Model endpoints

③ Key Design Decisions & Data Flow
Design Concern Phase Approach Key Files / APIs Status
Service Principal IDs
App IDs differ across clouds		 Transform Scan all staging files for SP UUIDs → Create SPs on GCP via SCIM → Build old→new map → Patch every JSON file in-place sp_migrator.py
SCIM /ServicePrincipals		 ✓ Automated
Node Type Mapping
Azure VM sizes → GCP types		 Transform CSV lookup table maps Azure VM SKUs to GCP machine types. Applies to clusters, jobs, pipelines. Optional zone_id hint per type. node_type_mapping.csv
import_jobs_gcp.py		 ✓ Automated
GCP Attributes
Cloud-specific cluster config		 Transform Strip azure_attributes. Inject gcp_attributes with availability (auto-mapped from Azure: ON_DEMAND / SPOT / SPOT_WITH_FALLBACK). Read from gcp_import_config.json. gcp_import_config.json
import_jobs_gcp.py		 ✓ Automated
Warehouse ID Mapping
Genie Spaces reference old IDs		 Transform Extract original warehouse IDs from jdbc_url in sql_warehouses.json. Match by name on GCP target. Create if missing. Patch genie_spaces.json with new IDs. extra_importers.py
SQL Warehouses API		 ✓ Automated
Genie Space Migration
serialized_space not public		 Import Warehouse IDs are resolved and patched automatically. API creation attempted; fails because serialized_space is an internal protobuf. Warning includes correct target warehouse_id for manual UI recreation. POST /api/2.0/genie/spaces
extra_importers.py		 ⚠ Manual UI
Instance Pool Ordering
Clusters/jobs reference pool IDs		 Import Pools imported first. Old pool IDs preserved in instance_pools.log so ClustersClient.get_instance_pool_id_mapping() can build the old→new remapping before clusters/jobs are imported. migration_pipeline.py
ClustersClient		 ✓ Automated
Resumable Pipeline
Partial failures / reruns		 Staging CheckpointService tracks each completed component. On re-run, already-imported items are skipped. Checkpoints can be manually deleted to force reimport. CheckpointService
import_jobs.log		 ✓ Automated
Workspace Files
Non-notebook file types		 Export Custom exporter walks workspace tree, downloads all FILE-type objects preserving directory structure. Supported: .py .sql .md .yaml .toml .json .csv .txt .sh .mhtml .ipynb workspace_files.py
GET /api/2.0/workspace/export		 ✓ Automated
④ Key Scripts & Modules

🚀 Main Export Orchestrator

migrate_workspace.sh

Entry point for export. Generates session ID, runs Step 0 inventory, then orchestrates Python export modules. Writes session banner and export report.

📥 GCP Import Orchestrator

import_gcp.sh

End-to-end import pipeline: SP migration → GCP transform → databrickslabs/migrate → extra_importers → comparison report. Handles exit code 2 (warnings) gracefully.

📦 Full Export Engine

workspace_export/full_export.py

Python export engine calling Databricks REST APIs for all 16 component types. Writes export_status.json and generates export_report.html.

🔄 SP Reconciliation

workspace_import/sp_migrator.py

Scans all staging files for SP app IDs. Creates missing SPs on GCP via SCIM. Patches every reference in JSON exports. Guard against in-place source=staging overwrite.

🔧 GCP Job Transform

import_jobs_gcp.py

Pre-processes instance_pools.log, clusters.log, jobs.log for GCP. Maps node types via CSV, injects gcp_attributes, strips Azure fields, applies availability mapping.

📡 Extra Importers

workspace_import/extra_importers.py

Handles 7 components not in databrickslabs/migrate: SQL Warehouses, DLT Pipelines, Git Repos, Lakeview Dashboards, Genie Spaces (with warehouse reconciliation), Model Endpoints, Workspace Files.

📊 HTML Report Generator

workspace_import/html_reporter.py

Generates self-contained export_report.html and import_report.html with tabbed layout, KPI cards, component tables, paths section and checklist. Embeds Databricks logo.

📈 Comparison Report

workspace_import/compare_report.py

Side-by-side comparison of exported vs imported component counts. Highlights errors and coverage gaps. Generates comparison_report.html with sortable tables.

🗂 Workspace Inventory

workspace_inventory.py

Standalone inventory tool using direct REST APIs. Generates inventory_pre_export.html with summary dashboard + 16 detail tabs, each with search, sort and pagination.

📁 Workspace File Exporter

workspace_export/exporters/workspace_files.py

Downloads all non-notebook workspace files preserving folder hierarchy. Writes workspace_files_manifest.json for import replay.

📁 Workspace File Importer

workspace_import/workspace_files_importer.py

Reads manifest, creates target directories, uploads files via workspace import API with base64 encoding. Skips existing files unless overwrite=True.

🎛 Pipeline DAG

workspace_import/migration_pipeline.py

Defines the task dependency graph for the databrickslabs/migrate import pipeline. Ensures instance pools are created before clusters, clusters before jobs.

⑥ Known Limitations & Manual Steps
🧞 Genie AI Spaces
The serialized_space protobuf field required by the create API is not exposed by any public export endpoint. Warehouse IDs are automatically resolved & patched. Recreation via UI takes ~2 minutes per space.
🔑 Secret Values
Secret scope names and ACLs are created automatically. Actual secret values cannot be read via the API (by design). Must be re-inserted manually or via a secrets provisioning tool.
🏛 Unity Catalog Data
UC schema / table DDL is exported as SQL files. Underlying data files in object storage are not moved by this tool — requires separate data pipeline or storage migration.
🤖 MLflow / Model Registry
MLflow experiments, runs and registered models are not migrated by this tool. Use mlflow-export-import for fine-grained MLflow migration.
📦 Git Repo Contents
Git repo metadata (remote URL, branch, sparse checkout) is migrated. Actual repository data lives in the remote Git provider and is re-cloned by Databricks on first checkout.
🌐 Network / Firewall
This tool runs on the operator's machine, not inside the cloud. Both workspace URLs must be reachable. VPN or Direct Connect may be required for private-endpoint workspaces.
